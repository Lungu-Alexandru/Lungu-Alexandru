# Gettiks.com — Platformă de ticketing

Instrucțiuni rapide:

1. Copiază `.env.example` în `.env.local` și completează cheile Firebase și Stripe
2. Instalează dependențele: `npm install`
3. Rulează local: `npm run dev`
4. Emulare funcții: `cd functions && npm install && npm run serve`

Stack: Next.js 14 (App Router) + Tailwind CSS + Firebase (Auth, Firestore, Storage, Functions) + Stripe
